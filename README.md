# homebrew-tap

Homebrew tap for tools published by [flushwhy](https://github.com/flushwhy).

## Install `fe`

Requires macOS and [Homebrew](https://brew.sh/).

```sh
brew tap flushwhy/tap
brew install fe
```

This formula installs the latest pinned release of [`fe`](https://github.com/flushwhy/fe) for Apple Silicon and Intel Macs. Formula updates are submitted as pull requests in this repository.
